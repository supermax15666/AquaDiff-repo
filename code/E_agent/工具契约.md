# E 臂工具契约（JSON Schema，方案 v2.15/v2.16 §3.E）

> 本文件是 Agent 工具栈的正式接口定义（代替独立 MCP server——v2.15 记录性决定）。
> 宿主程序是唯一工具调用方；LLM 不直接调用工具，只产出意图 JSON 与终答 JSON。
> 全部工具为本地确定性实现：DuckDB 只读、冻结 ML registry（ffbc8b45…）、冻结溶解度表。

## 1. 工具一：实验记录查询 `query_experimental_records`

```json
{
  "name": "query_experimental_records",
  "input_schema": {
    "type": "object",
    "required": ["system", "temperature_K", "concentration_mol_L"],
    "properties": {
      "system": {"enum": ["NaCl-H2O", "KCl-H2O", "LiCl-H2O", "CaCl2-H2O"]},
      "temperature_K": {"type": "number", "minimum": 0},
      "concentration_mol_L": {"type": "number", "minimum": 0}
    }
  },
  "output_schema": {
    "type": "object",
    "required": ["hit"],
    "properties": {
      "hit": {"type": "boolean"},
      "median_diffusion_1e9_m2_s": {"type": "number"},
      "n_records": {"type": "integer", "minimum": 1},
      "value_min_1e9_m2_s": {"type": "number"},
      "value_max_1e9_m2_s": {"type": "number"},
      "lineage_ids": {"type": "array", "items": {"type": "string"}},
      "references": {"type": "array", "items": {"type": "string"}},
      "match_rule": {"const": "exact (system, temperature_K, concentration_mol_L)"}
    }
  }
}
```

语义：精确匹配（浮点等值）。多记录条件返回**中位数**（与 642 gold 策略一致，已验证 642/642
逐位一致）并列出全部谱系与文献。库 = 四工作簿 Confirmed_Records 全量 785 条（含 3 条亚稳
过饱和实测记录——按 v2.16 实测优先返回，不因其超饱和而隐藏）。

## 2. 工具二：专用模型预测 `predict_specialized_model`

```json
{
  "name": "predict_specialized_model",
  "input_schema": { "$ref": "工具一 input_schema" },
  "output_schema": {
    "type": "object",
    "required": ["accepted"],
    "properties": {
      "accepted": {"type": "boolean"},
      "refusal_reason": {"type": "string"},
      "out_of_domain_fields": {"type": "array", "items": {"enum": ["temperature_K", "concentration_mol_L"]}},
      "domain": {"type": "object"},
      "prediction_1e9_m2_s": {"type": "number"},
      "model_key": {"enum": ["polynomial_ridge", "rbf_svr", "random_forest", "gradient_boosting", "gaussian_process"]},
      "registry_fingerprint": {"const": "ffbc8b45…63ad6"}
    }
  }
}
```

语义：先做矩形盒适用域检查（registry 冻结域，逐体系 T/c 闭区间）；域外 → `accepted=false`
+ 出域字段与范围（结构化拒绝，不输出预测值）；域内 → 冻结模型预测。调用前必须已通过
DB 未命中与饱和夹取（宿主路由保证）。

## 3. 工具三：饱和检查 `check_saturation`

```json
{
  "name": "check_saturation",
  "input_schema": { "$ref": "工具一 input_schema" },
  "output_schema": {
    "type": "object",
    "required": ["checked", "exceeded"],
    "properties": {
      "checked": {"type": "boolean", "description": "T 在表范围 [273.15, 373.15] K 内才检查"},
      "exceeded": {"type": "boolean", "description": "c > c_sat * (1 + tau)，tau=0.01"},
      "c_sat_mol_L": {"type": "number", "description": "线性插值"},
      "solid_phase_at_T": {"type": "string"},
      "ratio_to_saturation": {"type": "number"}
    }
  }
}
```

语义：冻结溶解度表（`frozen/solubility_frozen.json`，records_content_sha256 `b7d40c4f…`）
同体系内按 T 线性插值；τ=1% 防近饱和误触发。**仅作用于 DB 未命中路径**（v2.16）。

## 4. LLM 阶段一：意图提取（锚点 Qwen3-4B-Instruct-2507）

输入：问题原文。输出 schema：

```json
{
  "type": "object",
  "required": ["status"],
  "properties": {
    "status": {"enum": ["ok", "ambiguous", "unsupported", "missing_fields"]},
    "system": {"enum": ["NaCl-H2O", "KCl-H2O", "LiCl-H2O", "CaCl2-H2O"]},
    "temperature_K": {"type": "number"},
    "concentration_mol_L": {"type": "number"},
    "temperature_unit": {"enum": ["K", "C", "F", "unknown"]},
    "concentration_unit": {"enum": ["mol/L", "g/L", "mmol/L", "unknown"]},
    "issues": {"type": "array", "items": {"type": "string"}}
  }
}
```

宿主对 LLM 输出做最终裁决：单位换算（°C/°F→K 精确换算、g/L→mol/L 用体系摩尔质量、
mmol/L→mol/L）；`mol/kg`（molality）与 `wt%` 因需溶液密度**不可安全换算** → 澄清/拒绝；
缺参、歧义、体系不支持 → 澄清或结构化拒绝（LLM 判定仅供参考，宿主兜底）。

## 5. LLM 阶段二：终答誊写

输入：问题原文 + 工具结果块（数值/来源/说明，宿主注入）。输出 schema：

```json
{
  "type": "object",
  "required": ["answer_type"],
  "properties": {
    "answer_type": {"enum": ["value", "refusal", "clarify"]},
    "diffusion_1e9_m2_s": {"type": "number"},
    "source_type": {"enum": ["experimental_record", "specialized_model", "none"]},
    "source_reference": {"type": "string"},
    "notes": {"type": "string"}
  }
}
```

**宿主硬校验**（载荷忠实率）：`diffusion_1e9_m2_s` 必须与工具输出逐字一致（字符串级比较
再数值确认）；`source_type`/`source_reference` 必须与工具块一致；超饱和披露与夹取说明必须
保留。不一致 → 记忠实性失败，以宿主持有的工具值为准判分。

## 6. 路由总序（v2.16）

```
意图提取 → 宿主校验/换算 → DB(原始条件) ─ 命中 → 实测值+来源（超饱和附披露）
                                    └ 未命中 → 饱和检查 ─ 超 → 明示+夹取 → 重入路由(DB(夹取)→域盒)
                                                              └ 未超 → 域盒 ─ 域内 → ML
                                                                            └ 域外 → 结构化拒绝
        → LLM 誊写 → 宿主硬校验 → 记录（路由标签、忠实性、延迟）
```

路由真值（评测用）：由池内成员资格（DB 精确命中）、溶解度表、矩形盒域机械推导；
642 主集 = 全 DB 命中（检索忠实度口径）；外部集 = 7 DB / 41 ML / 16 拒绝；挑战集 =
逐题机械推导并随集冻结。
