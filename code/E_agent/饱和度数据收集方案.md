# 四体系溶解度数据收集方案（E 臂饱和安全层，方案 v2.15 §3.E 第 3 步）

> 用途：Agent 路由的物理适用域——若输入浓度 c > c_sat(T)·(1+1%)，Agent 明示判定并按
> c_sat(T) 夹取后继续路由（DuckDB → ML 域盒 → 拒绝，夹取不豁免后续检查）。
> 表述边界：过饱和溶液亚稳存在，本机制是**安全近似策略**，论文不写"物理上不可能"。
> 本表在 Agent 评测前冻结（哈希 + manifest），冻结后不改动；改动需新版本。

## 1. 数据要求

| 项 | 要求 |
|---|---|
| 体系 | NaCl–H₂O、KCl–H₂O、LiCl–H₂O、CaCl₂–H₂O 四体系 |
| 温度范围 | **273.15–373.15 K**（覆盖全部矩形盒域 + KCl 100 °C 外部行；T 超出表范围时 Agent 不做饱和检查，交由域盒处理） |
| 浓度单位 | **mol/L（molarity）**，与 Agent 管线一致 |
| 温度点密度 | 优先原始表格 native 点位；保证每 20 K ≥1 点；**每个水合物相变拐点两侧各 ≥1 点**（LiCl/CaCl₂ 曲线分段） |
| 固相标注 | solid_phase 栏必填（如 CaCl₂·6H₂O / CaCl₂·4H₂O、LiCl·H₂O / LiCl·2H₂O / LiCl·3H₂O；NaCl/KCl 为无水盐）——供 precheck 分段单调性检查与论文方法表述 |
| 来源 | 逐点可引用（作者/年/表页）；换算依据逐条留档 |

**单位换算**（原始数据常为 g/100 g H₂O，即 molality 基）：
c (mol/L) = 1000·ρ·m / (1000 + m·M₂)，其中 m 为 mol/kg，ρ 为**该饱和溶液密度**（g/mL），
M₂ 为溶质摩尔质量（NaCl 58.44 / KCl 74.55 / LiCl 42.39 / CaCl₂ 110.98 g/mol）。
公式与 B2 外部行换算一致；密度来源必须可引用并填入 conversion_basis。

## 2. 推荐来源

1. **CRC Handbook 92nd ed.**（已有 PDF：`02_数据\07_方法参考文献\`）：
   "Solubility of Inorganic and Organic Compounds in Water" 表（g/100 g H₂O + 固相标注，多温度点）；
   饱和溶液密度可查同版溶液性质表或用原始文献值。
2. **IUPAC-NIST Solubility Data Series**（权威评估系列）：优先作为主源或交叉验证；
   同体系多源分歧 >2% 时在 notes 记录并择一采用（不混用拟合值）。
3. 原始文献（如需要更细温度网格）。

## 3. 录入模板

`py/E_Agent/饱和度录入模板.xlsx`（Solubility_Records 仅表头 + 说明表；**不填示例值**，防混入数据）。
列契约：

| 列 | 说明 |
|---|---|
| system_id | NaCl-H2O / KCl-H2O / LiCl-H2O / CaCl2-H2O |
| temperature_K | 开尔文（如 298.15） |
| c_sat_mol_L | 饱和浓度（mol/L，换算后） |
| original_value | 原始数值 |
| original_basis | g_per_100g_H2O / molality_mol_kg / other（注明） |
| conversion_basis | 直接给出 mol/L 则填 "direct"；否则填密度值+来源（如 "ρ=1.202 g/mL, CRC 92nd Table X"） |
| solid_phase | 平衡固相（水合物分子式；无水盐写 anhydrous） |
| source_citation | 作者/年/表页（如 "CRC 92nd, Sec.8, Solubility table"） |
| accessed_date | 查阅日期 |
| notes | 相变拐点、分歧、取舍等 |

## 4. precheck（助手已备：`py/E_Agent/precheck_solubility.py`）

检查项：列完整性与取值域；每体系温度覆盖（273.15–373.15、每 20 K ≥1 点）；
**同固相分段内 c_sat 随 T 单调递增**（相变拐点处允许跳变）；
量级合理性（与文献常识粗核）；与池内最大浓度交叉核对（警告级：池内最大 c
— NaCl 5.4 / KCl 4.45 / LiCl 8.1108 / CaCl₂ 6.004 M — 对应温度下不应明显超过 c_sat）；
固相栏填写。全部通过后方可冻结。

## 5. 冻结与使用

- precheck 全通过 → 冻结：`py/E_Agent/frozen/solubility_frozen.json`（内容 SHA-256 + manifest）。
- Agent 侧插值规则：同体系内按 T 线性插值；跨固相段插值允许（线性近似，论文如实标注）；
  触发阈值 τ=1%（c > c_sat·1.01 才触发，防近饱和有效查询误触发；τ 已在方案 v2.15 冻结）。
- 预期影响：642 主集与外部 64 题均无触发（池内与外部高浓行均在溶解度以内——见方案 v2.15 版本记录）；
  主要测试面为挑战集的超饱和/近饱和题。
