# Figure scripts

Plotting scripts for the main-text figures (`main/`) and Supporting Information
figures (`si/`), plus data-table aggregation helpers (`aggregation/`).

The scripts were written inside the original working archive and expect the figure
source tables in a sibling `09_共享_绘图数据/` folder; in this repository those tables
live in `archive/metrics/plot_data/`. Adjust the input paths at the top of each
script (or symlink/copy the folder) before running.

Style helpers are in `main/common_style.py` and `si/common_style.py`.
