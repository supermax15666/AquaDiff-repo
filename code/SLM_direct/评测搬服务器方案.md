# 评测搬到服务器本机跑的方案（路线 B，备选）

> 适用：服务器 LM Studio 的 Local Server 无法对局域网开放、LMlink 又不稳定时。
> 原理：评测管道是纯本地程序，放到服务器上跑，直连服务器自己的 127.0.0.1:1234。

## 第 1 步：拷贝以下内容到服务器，保持目录结构

在服务器建 `D:\cet_eval\py\`，从本地拷贝：

```text
py\SLM_direct\                          ->  D:\cet_eval\py\SLM_direct\   （整个目录，含 config.json、run_benchmark.py、run_sft_27b_mastery_server.bat）
py\LLM_API_direct\                      ->  D:\cet_eval\py\LLM_API_direct\（整个目录：共享核心 + 642 题库/gold）
py\results\SLM_direct\protocol_v2_2\lm_studio__qwen3_6_27b_sft_q4km__qwen3.6-27b-lora-r64\
                                        ->  D:\cet_eval\py\results\SLM_direct\protocol_v2_2\<同名目录>\
```

（第三个目录是**断点状态**：已完成 40 次样本 + state.sqlite3，拷贝它才能续跑不重跑。
拷不动的文件可跳过——管道会按断点重建，缺样本最多重跑几题。）

## 第 2 步：确认服务器上模型已加载

服务器 LM Studio 里 `qwen3.6-27b-lora-r64` 处于加载状态（Reasoning=Off、CUDA runtime）。
服务器本地 `http://127.0.0.1:1234/v1/models` 应能列出该模型。

## 第 3 步：装依赖并运行

```powershell
cd D:\cet_eval\py\SLM_direct
python -m pip install openpyxl
run_sft_27b_mastery_server.bat
```

（Python 3.13 已在服务器上；config.json 里的 server.base_url 已是 localhost:1234，
在服务器上正好指向自己，无需改动。）

## 第 4 步：跑完回传

跑完后把 `D:\cet_eval\py\results\SLM_direct\protocol_v2_2\lm_studio__qwen3_6_27b_sft_q4km__qwen3.6-27b-lora-r64\`
整个目录拷回本地同名位置（覆盖合并），告诉我，我做 642 掌握度分析
（analyze_results.py 单 run 分析，SFT vs Base 配对）。
