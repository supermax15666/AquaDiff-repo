## 4. 论文表述口径（红线）

1. 外部前瞻集结果按**前瞻外部评估**表述（三组同资格：Base/SFT/ML 均在冻结后首次接触该集）；
   642 主集结果仍为回顾性探索。
2. 三组差异为描述性比较：ML 无抽样 CI，不与 LLM 臂做显著性宣示；SFT−Base 配对显著性见
   `external_comparison_summary.md`（+43.8~+73.4pp，全部 p<0.001）。
3. ML 域外拒绝是**设计要求的安全行为**而非失败；全题口径将其计错仅为与 LLM 臂可比。
   两套口径（全题/域内）必须同时报告，不得只报其一。
4. 不声称 ML 或 SFT 之一"更优"作为总体结论：SFT 全题分数略高但无拒绝机制、
   在域外条件上继续给出答案；ML 域内近满分且域外显式拒绝——两者互补性（Agent 路由的
   DuckDB 命中→ML 预测→域外拒绝三段式）正是 E 臂设计依据。
5. 本文件与 ML 运行产物不含 gold 值与逐题误差（密封纪律，仅聚合指标；
   第 5 节分解使用各场分析已产出的逐题正确率与 ML 域标记，同样不接触 gold）。
## 5. 域内/域外分解（2026-08-25 补充；题均口径，来自各场逐题结果与 ML predictions.csv 的域标记）

把 64 题按 ML 矩形盒适用域分成"域内 48 题 / 域外 16 题"后，三组的真实格局：

| 组 | 域内 48 题 Acc@10% | 域外 16 题 Acc@10% |
|---|---|---|
| Base（5 模型） | 6.2–39.6%（均值 21.1%） | 0.0–25.0% |
| SFT（5 模型） | 91.7–100.0%（均值 93.3%） | 12.5–43.8%（均值 30.0%，即约 7 成域外答案是错的且无任何警示） |
| **冻结 ML** | **97.9%（47/48）** | **结构化拒绝 16/16（零错误数字输出）** |

**解读（论文讨论要点）**：
1. 域内：ML（97.9%）高于全部 SFT 模型（除 Gemma 100%）与 SFT 均值（93.3%）——
   Agent 路由（§3.E）只把域内条件交给 ML，因此 Agent 的 ML 后端答案质量 ≈ 98%。
2. 域外：SFT 被迫作答，约 70% 是错的且不带置信警示；ML 全部拒绝、零错误数字。
   "71.9% 全题口径低于 SFT"的表象完全由"拒绝计错"惯例造成——若按 Agent 安全口径
   （域外正确拒绝 = 正确行为），ML 的可用性结论反转。
3. E 臂的三段式路由（DuckDB 命中→ML→域外拒绝）由此获得直接实证依据：
   域内交给近满分的 ML，域外交给显式拒绝，两条路径都不产生"自信的错误答案"。
